### Automatically Collected Information
- Device information
- Browser type and version
- IP address

## How We Use Your Information

We use collected information to:
- Provide tax calculation services
- Process bank statement imports
- Send tax deadline reminders

## Data Storage

- All data is stored securely using industry-standard encryption

You have the right to:

- Transaction data: Retained for 7 years (tax compliance)

## Security

- Secure database storage

- Access controls
