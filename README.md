## 🌟 Overview

<div align="center">

**PayLockr** is a purpose-built financial intelligence platform for Indian freelancers navigating the complexities of the **FY 2025-26 New Tax Regime**.

<br/>

<img src="https://img.shields.io/badge/🎯-Real--Time_Tax_Engine-22d3ee?style=for-the-badge" />
<img src="https://img.shields.io/badge/🤖-AI_Powered_Parsing-6366f1?style=for-the-badge" />
<img src="https://img.shields.io/badge/🔒-Auto_Vaulting-10b981?style=for-the-badge" />

</div>

<br/>

Whether you earn via UPI, NEFT, or international wire transfers, PayLockr ingests, classifies, and analyzes every transaction — so your tax season is never a surprise.

<br/>

<div align="center">

### 💡 Problem vs Solution

| 😰 Problem | ✅ PayLockr Solution |
|:---|:---|
| **Surprise tax bills at year-end** | Real-time tax estimation all year |
| **Manual bank statement parsing** | AI extracts every transaction automatically |
| **Forgetting to save for taxes** | Automatic 10% vault on every income |
| **Missing advance tax deadlines** | Built-in quarterly calendar & reminders |
| **Unknown deductible expenses** | AI-powered recommendations & categorization |

</div>

## ✨ Features

<div align="center">

### 🧮 Smart Tax Calculator

<img src="https://img.shields.io/badge/FY_2025--26-New_Tax_Regime-6366f1?style=for-the-badge" />

</div>

- 📊 Real-time estimation following **FY 2025-26 New Tax Regime** slabs
- 📈 Progressive brackets: **0% → 5% → 10% → 15% → 20% → 25% → 30%**
- 💰 Automatic **₹75,000 standard deduction** applied
- 🎁 **Section 87A rebate** (up to ₹60,000 for income ≤ ₹12L) factored in
- 📅 Accurate **monthly projections** computed from actual transaction dates

<br/>

<div align="center">

### 🔒 Automatic Tax Vault

<img src="https://img.shields.io/badge/Auto_Save-10%25_on_Income-10b981?style=for-the-badge" />

</div>

- 💸 **10% auto-save** triggered on every income credit
- 🏦 Dedicated vault with real-time balance tracking
- 📊 **Tax coverage meter** — visualize your readiness before deadlines
- ⏰ Quarterly advance tax **reminders built-in**

<br/>

<div align="center">

### 📥 AI-Powered Bank Statement Import

<img src="https://img.shields.io/badge/Powered_by-Google_Gemini_AI-4285F4?style=for-the-badge&logo=google&logoColor=white" />

</div>

```
📄 Upload PDF → 🤖 Gemini Vision Extracts → ✅ Auto-Categorized Transactions
```

- 🧠 **Gemini Vision AI** extracts transactions from any format, any layout
- 🏦 Universal support for **all Indian banks**: HDFC, ICICI, SBI, Axis, Kotak, PNB, BOB, and more
- 📑 Handles **multi-page PDFs** and **screenshot images**
- 🏷️ Auto-classification: `UPI` `NEFT` `IMPS` `RTGS` `ATM`
- 🎯 Smart labeling: Credits → Business Income · Debits → Expense categories

<br/>

<div align="center">

### 📊 Financial Insights & Analytics

- 📈 Monthly income vs. expense breakdown with **interactive charts**
- 📉 Cashflow trend analysis and **income growth tracking**
- 📝 Deductible expense identification for **ITR preparation**

## 🚀 Quick Start

<div align="center">

### Prerequisites

```
Node.js 18+    →  https://nodejs.org
Python 3.11+   →  https://python.org
Git            →  https://git-scm.com
```

</div>

<br/>

### ⚡ Lightning Setup (3 Steps)

```bash
# 1️⃣ Clone the repository
git clone https://github.com/saiyamjain468/paylockr.git
cd paylockr

# 2️⃣ Run PayLockr
# Windows
scripts\start-paylockr.bat

# macOS / Linux
npm run dev

# 3️⃣ Open browser → http://localhost:5173
```

## 🏗️ Architecture

<div align="center">

```
┌─────────────────────────────────────────────────────────────┐
│                    🖥️  FRONTEND LAYER                       │
│              React + TypeScript + Vite                      │
├─────────────────────────────────────────────────────────────┤
│  📊 Dashboard  │  💳 Transactions  │  🔒 Tax Vault         │
│  📅 Calendar   │  💡 Insights      │  ⚙️  Settings         │
└─────────────────────────────────────────────────────────────┘
                            ↕️
┌─────────────────────────────────────────────────────────────┐
│                  ⚡ DOCUMENT SERVICE                         │
│                Python + FastAPI                             │
├─────────────────────────────────────────────────────────────┤
│  🤖 Gemini Vision  │  📄 PDF Parser  │  🏷️  Categorizer   │
└─────────────────────────────────────────────────────────────┘
```

### Data Flow Pipeline

```
📄 Bank Statement (PDF/Image)
        ↓
🤖 Gemini Vision API → Extract Transactions
        ↓
🏷️  Smart Categorizer → Classify Income/Expenses
        ↓
🧮 Tax Engine → Calculate Real-time Tax
        ↓
🔒 Vault Manager → Auto-save 10% to Tax Vault
        ↓
📊 Dashboard → Visual Insights & Alerts
```

</div>

## 📱 Usage Guide

<div align="center">

### 🎯 Three Simple Steps

</div>

<br/>

**1️⃣ Import Your Bank Statement**
```
Navigate to Transactions → Click "IMPORT" → Upload PDF/Screenshot
→ AI extracts automatically → Review & Confirm → Done in 60 seconds!
```

**2️⃣ View Your Tax Breakdown**
```
Open Dashboard → See real-time income, tax liability, vault balance
→ Check quarterly payment schedule → Never miss advance tax again
```

**3️⃣ Track & Optimize Expenses**
```
All debits auto-categorized → Filter by category/date/amount
→ Identify deductible expenses → Export for CA or ITR filing
```
